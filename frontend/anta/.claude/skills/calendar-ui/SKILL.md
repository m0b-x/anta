# Calendar UI

Every calendar surface speaks the app's UI language, and the calendar is where it was set (the 2026-09-25 event editor redesign — [docs/event-editor-redesign-roadmap.md](../../../docs/event-editor-redesign-roadmap.md) §2–§3 holds the owner's decisions D1–D20 and the token spec). **The rulebook is the `ui-language` skill; load it first.** The idioms, the row primitives, the sheet chrome, the metrics and the tests every surface ships with are there. This skill holds only what is the calendar's own.

**Adoption.** `docs/calendar-language-adoption-roadmap.md` (2026-09-27, the owner's max-effort plan for every calendar surface still outside the language, four tiers) is being worked, and the drive-by rule of `ui-language` is suspended while it runs: read it before touching any calendar sheet or page, and update its §9 status table per tier. §9 is also where to read which calendar surfaces speak the language today.

## Shared pieces

- **`EventAvatar(icon:, color:)`** — radius 20, icon 24, background at α 0.16. The colour follows `EventSummaryProvider.colorFor` (the custom colour only while `tintIcon`, else the category colour). The **bar** rule (`colorValue ?? category`) is a different thing and belongs to grid bars, rails and stripes.
- **`AgendaPeriodNav`** — chevron | title + count | a fixed 48 dp today slot | chevron. `onTitleTap` makes the title the jump control (drop-down glyph, opens `MonthYearPickerSheet`). Null callbacks disable; the fixed slot is what keeps the title from shifting. The title may take two lines (`FormMetrics.periodTitleMaxLines`) in a box as tall as the tallest title the row will show — pass `month:` on a month nav so the box is measured over that year's twelve titles and paging never moves the grid; a year nav passes nothing. The twelve are laid out once per key and kept in a static `LruCache` (`yearTitleCacheSize`) keyed on every input of their layout, so a rebuild lays out only the shown title — a new input to that layout joins the key. The count is a semantics node of its own and shrinks to fit one line inside a box of its one-line height, never cut and never taller. `previousIdentifier` / `nextIdentifier` / `todayIdentifier` / `titleIdentifier` are optional ids, set only where a flow walks the nav (the day list's `day-list-nav-*`).
- **`YearMonthTile` + `MonthDotMatrix`** — the year overview's tiles, shared by the drill-down and the Dates sheet's year view. `YearMonthTile.gridDelegate` is the grid; `dayColors` paints per-day colours, `missedMask` / `dayMissedAlpha` fade missed days. One `Semantics` node per tile, the matrix excluded.
- **Day grids** render `CalendarDayCell` + `CalendarDayBars`, never table_calendar's own decorations. Dates go through `CalendarDatePickerSheet`, times through `TimePadSheet`, categories through `CategoryPickerSheet`, month/year through `MonthYearPickerSheet` — never `showDatePicker` or `showTimePicker`.

## Semantics and automation

- `SemanticsIds` are the QA driver's contract: add one (kebab-case, never renamed) for any control a device script must hit whose label is not unique text — bar buttons, the halves of a paired control, a field. Since 2026-09-26 every editor row takes `identifier:` (`FormPickerRow`, `FormSwitchRow`, `FormActionRow`, `FormMenuRow`), the header takes `leadingIdentifier:`, the editor's body scroll view is `event-form`, its description surface `event-description` (a container above the editor's own node, 2026-09-30), the sub-sheets' Done are `repeat-done` / `look-done`, the Dates sheet's Save / Cancel are `date-picker-save` / `date-picker-cancel`, the detail sheet's Edit / Close are `event-detail-edit` / `event-detail-close` and its rows `event-detail-description` / `-present` / `-missed` / `-skip` / `-add-date` / `-dates` / `-note` (2026-09-26), and a day-panel row is `SemanticsIds.eventRow(event.id)`; since Tier 1 (2026-09-27) the agenda filters sheet's rows and menu items are `agenda-filter-*` (the panel's tune button `agenda-filter-open`), the Dates sheet's Today slot `date-picker-today`, the month/year picker `month-year-close` / `-apply` / `-today` / `-typed`, the description sheet `description-close` / `-done`, the template picker `template-pick-close` / `-blank` / `templatePickRow(id)`, the icon picker `icon-pick-close` / `-search`, the sound sheet `sound-close` / `-inherit` / `-phone-default` / `-from-phone`, the Look sheet's `look-close` / `look-icon` / `look-color` (the colour strip a container node, never a merge over its swatches); the Custom sub-sheet's `alert-custom-close` / `-done` / `-unit-minutes` / `-hours` / `-days` / `-less` / `-more`; the quick alarm's `quick-alarm-close`, `quick-alarm-preset-20` / `-60` / `-tonight`, `quick-alarm-type-reminder` / `-alarm` beside the kept `quick-alarm-time` / `-name` / `-save` / `-remove-after`; the template form's `template-close` / `-save` / `-name` / `-category` / `-look` / `-description` / `-all-day` / `-starts` / `-ends` / `-ends-clear` / `-repeat` / `-count` / `-count-style-numbered` / `-elapsed` / `-presence` / `-assume-present` / `-absent` / `-per-day` / `-priority` and `templatePriorityItem(p)`; since Tier 3 (2026-10-03) the day list's `day-list-close` / `-back`, `day-list-mode-list` / `-month` / `-year`, `day-list-scope-upcoming` / `-calendar-year`, `day-list-whole-month`, `day-list-body` and its nav's `day-list-nav-previous` / `-next` / `-today` / `-title` (one set — the month nav and the year nav never share a screen), each summary card's days button `agendaCardDays(key)` (`agenda-card-days-<key>`, its `:` as `-`); the category editor's `category-editor-close` / `-save` / `-name` / `-icon`; the swatch strip's `swatch-row` (the container where the Look sheet has `look-color`), `swatch-default` / `-add` / `-manage` and its menu's `swatch-menu-edit` / `-delete` / `-manage`; the fasting schedule's `fasting-schedule-close`, `fastingWeekday(n)` (`fasting-weekday-1` … `-7`), `fasting-weekdays-all` / `-none`, `fasting-weekday-scope-weekly` / `-all`, `fastingMonth(n)` (`fasting-month-1` … `-12`), `fasting-months-all` / `-none`, `fasting-month-scope-weekly` / `-all`, `fasting-days-off`, `fasting-extra-days` and `fastingDateRemove(kind, date)` (`fasting-skip-remove-<yyyy-MM-dd>` / `fasting-force-remove-…`); the fasting style's `fasting-style-close`, `fasting-style-grid` with its items `fasting-style-grid-tint` / `-bar` / `-strong` / `-none`, `fasting-style-placement` with `fasting-style-placement-first` / `-before-holidays` / `-after-holidays` / `-last`, `fasting-style-icon` / `-icon-reset` / `-title` / `-title-clear` / `-description`; removed holidays' `removed-holidays-close` and `holidayRestoreButton(nameKey, date)` (`holiday-restore-<nameKey>-<yyyy-MM-dd>`); the palette's `palette-close` / `-add` / `-reset` and `paletteRow(hex)` / `paletteHandle(hex)` / `paletteDelete(hex)` (`palette-row-<rrggbb>`, the hex lower-cased without its `#`); the colour picker's `color-picker-close` / `-select`, `color-mode-square` / `-wheel`, `color-hex`, `color-copy-hex`. A dynamic helper spells its argument the way a flow can: a date as `yyyy-MM-dd` (`{{day+N}}`), a hex lower-cased. A form sheet's drag surface is `excludeFromSemantics: true` (`FormSheetFrame` — its drag callbacks otherwise read as a scrollable) and a sheet whose root is a `Focus` (the time pad) sets `includeSemantics: false` so the header's title stays its own node. **A new row in the editor gets an id in the same change**, and the flow that walks its screen (`tool/qa/flows/calendar/`) is updated in the same slice.
- **Titles are not targets on the calendar page**: every marked day cell's marker label carries its events' titles, so a row is addressed by `id:event-row-<eventId>`. Day cells themselves can carry no id (`table_calendar` wraps them with excluded semantics); a flow taps a day by its label, `{{longdate+N}}`.
- The filter surfaces' ids: `filter-…` on the sheet, `filter-list-…` on the check list, `category-pick-…` on the picker, `filter-preset-…` on the presets, `calendar-filter-open` / `calendar-saved-filters-open` on the bar.

## Device pass

Device pass through the `qa-emulator` skill: `qa relaunch --fresh --seed tool/qa/fixtures/calendar.json` then `qa flows calendar` — twenty-three saved flows since Tier 3. Tier 2's four (`13_alert_sheet`, `14_quick_alarm`, `15_templates`, `16_alert_defaults`) brought the pass to seventeen, about 90 s on the Windows emulator through the agent (`ANTA_QA_VIA=agent`); Tier 3's six joined on 2026-10-03: `17_day_list` (List · Month with a picked day and Whole month · Year in both scopes · a tile drilled and ← back), `18_category_editor` (the edit form, its icon picker, the create form's duplicate warning), `19_fasting_schedule` (the chips, the scope hints, the exception rows into the Dates sheet), `20_fasting_style` (the grid menu's items, the title dialog), `21_removed_holidays` (the seed's suppressed holiday restored — the flow consumes it, so a lone re-run needs `qa relaunch --fresh --seed`) and `22_palette` (the custom row's ids, the colour picker's two modes, the swatch menu by long press). Then `qa set theme=dark locale=de text-scale=2.0` for the matrix and the boards' screenshots side by side; `qa errors` clean. A new surface adds a flow file; a changed one updates its flow in the same slice. Two ways in: the day list opens from a summary card, so a flow sets the agenda's Event rows to the summary (`agenda-filter-event-rows` → `agenda-filter-event-rows-summary` → `agenda-filter-apply`), taps the card's `agenda-card-days-<key>` and resets the filters at the end; and on Calendar settings and the appearance page a section header ("Categories", "Appearance") wins the exact label pass over the row of the same name, so a row is tapped by its own second line ("Create and customize event categories", "Subtle tint · After holidays").
