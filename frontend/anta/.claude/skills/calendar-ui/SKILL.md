# Calendar UI

Every calendar surface speaks the app's UI language, and the calendar is where it was set (the 2026-09-25 event editor redesign — [docs/event-editor-redesign-roadmap.md](../../../docs/event-editor-redesign-roadmap.md) §2–§3 holds the owner's decisions D1–D20 and the token spec). **The rulebook is the `ui-language` skill; load it first.** The idioms, the row primitives, the sheet chrome, the metrics and the tests every surface ships with are there. This skill holds only what is the calendar's own.

**Adoption.** `docs/calendar-language-adoption-roadmap.md` (2026-09-27, the owner's max-effort plan for every calendar surface still outside the language, four tiers) is being worked, and the drive-by rule of `ui-language` is suspended while it runs: read it before touching any calendar sheet or page, and update its §9 status table per tier. §9 is also where to read which calendar surfaces speak the language today.

## Shared pieces

- **`EventAvatar(icon:, color:)`** — radius 20, icon 24, background at α 0.16. The colour follows `EventSummaryProvider.colorFor` (the custom colour only while `tintIcon`, else the category colour). The **bar** rule (`colorValue ?? category`) is a different thing and belongs to grid bars, rails and stripes.
- **`AgendaPeriodNav`** — chevron | title + count | a fixed 48 dp today slot | chevron. `onTitleTap` makes the title the jump control (drop-down glyph, opens `MonthYearPickerSheet`). Null callbacks disable; the fixed slot is what keeps the title from shifting.
- **`YearMonthTile` + `MonthDotMatrix`** — the year overview's tiles, shared by the drill-down and the Dates sheet's year view. `YearMonthTile.gridDelegate` is the grid; `dayColors` paints per-day colours, `missedMask` / `dayMissedAlpha` fade missed days. One `Semantics` node per tile, the matrix excluded.
- **Day grids** render `CalendarDayCell` + `CalendarDayBars`, never table_calendar's own decorations. Dates go through `CalendarDatePickerSheet`, times through `TimePadSheet`, categories through `CategoryPickerSheet`, month/year through `MonthYearPickerSheet` — never `showDatePicker` or `showTimePicker`.

## Semantics and automation

- `SemanticsIds` are the QA driver's contract: add one (kebab-case, never renamed) for any control a device script must hit whose label is not unique text — bar buttons, the halves of a paired control, a field. Since 2026-09-26 every editor row takes `identifier:` (`FormPickerRow`, `FormSwitchRow`, `FormActionRow`, `FormMenuRow`), the header takes `leadingIdentifier:`, the editor's body scroll view is `event-form`, its description surface `event-description` (a container above the editor's own node, 2026-09-30), the sub-sheets' Done are `repeat-done` / `look-done`, the Dates sheet's Save / Cancel are `date-picker-save` / `date-picker-cancel`, the detail sheet's Edit / Close are `event-detail-edit` / `event-detail-close` and its rows `event-detail-description` / `-present` / `-missed` / `-skip` / `-add-date` / `-dates` / `-note` (2026-09-26), and a day-panel row is `SemanticsIds.eventRow(event.id)`; since Tier 1 (2026-09-27) the agenda filters sheet's rows and menu items are `agenda-filter-*` (the panel's tune button `agenda-filter-open`), the Dates sheet's Today slot `date-picker-today`, the month/year picker `month-year-close` / `-apply` / `-today` / `-typed`, the description sheet `description-close` / `-done`, the template picker `template-pick-close` / `-blank` / `templatePickRow(id)`, the icon picker `icon-pick-close` / `-search`, the sound sheet `sound-close` / `-inherit` / `-phone-default` / `-from-phone`, the Look sheet's `look-close` / `look-icon` / `look-color` (the colour strip a container node, never a merge over its swatches); since Tier 2 (2026-10-02) the alert sheet's `alert-sheet-close`, `alert-type-reminder` / `-alarm`, `alert-when` with its menu items `alertWhenItem(n)` / `alertWhenDayItem(n)` / `alert-when-custom` / `alert-when-day-custom`, `alert-time-of-day`, `alert-sound`, `alert-remove-after`, `alert-remove`, its Done on the kept `alert-sheet-save`; the Custom sub-sheet's `alert-custom-close` / `-done` / `-unit-minutes` / `-hours` / `-days` / `-less` / `-more`; the quick alarm's `quick-alarm-close`, `quick-alarm-preset-20` / `-60` / `-tonight`, `quick-alarm-type-reminder` / `-alarm` beside the kept `quick-alarm-time` / `-name` / `-save` / `-remove-after`; the template form's `template-close` / `-save` / `-name` / `-category` / `-look` / `-description` / `-all-day` / `-starts` / `-ends` / `-ends-clear` / `-repeat` / `-count` / `-count-style-numbered` / `-elapsed` / `-presence` / `-assume-present` / `-absent` / `-per-day` / `-priority` and `templatePriorityItem(p)`. A form sheet's drag surface is `excludeFromSemantics: true` (`FormSheetFrame` — its drag callbacks otherwise read as a scrollable) and a sheet whose root is a `Focus` (the time pad) sets `includeSemantics: false` so the header's title stays its own node. **A new row in the editor gets an id in the same change**, and the flow that walks its screen (`tool/qa/flows/calendar/`) is updated in the same slice.
- **Titles are not targets on the calendar page**: every marked day cell's marker label carries its events' titles, so a row is addressed by `id:event-row-<eventId>`. Day cells themselves can carry no id (`table_calendar` wraps them with excluded semantics); a flow taps a day by its label, `{{longdate+N}}`.
- The filter surfaces' ids: `filter-…` on the sheet, `filter-list-…` on the check list, `category-pick-…` on the picker, `filter-preset-…` on the presets, `calendar-filter-open` / `calendar-saved-filters-open` on the bar.

## Device pass

Device pass through the `qa-emulator` skill: `qa relaunch --fresh --seed tool/qa/fixtures/calendar.json` then `qa flows calendar` (seventeen saved flows since Tier 2 — `13_alert_sheet`, `14_quick_alarm`, `15_templates`, `16_alert_defaults` joined on 2026-10-03 — about 90 s on the Windows emulator through the agent, `ANTA_QA_VIA=agent`), plus `qa set theme=dark locale=de text-scale=2.0` for the matrix and the boards' screenshots side by side; `qa errors` clean. A new surface adds a flow file; a changed one updates its flow in the same slice.
