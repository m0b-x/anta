# Localization — loads when a file under lib/l10n is touched

- Add, rename or remove keys in `app_en.arb`, `app_de.arb` and `app_ro.arb` **together**; German and Romanian are never left for later.
- After any ARB edit: `flutter gen-l10n`, then confirm `untranslated.txt` (at the app root, per `l10n.yaml`) reads `{}`.
- `app_localizations*.dart` are generated — never edit them by hand.
- Placeholder metadata blocks stay identical across the three files; Romanian plurals carry `few` as well as `one` / `other`.
- Load the `l10n` skill for copy style, ICU plural precedents and the "never an N×3 ARB matrix" rule.
