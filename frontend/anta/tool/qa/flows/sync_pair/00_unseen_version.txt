# A push meets a version it has not seen. The second guest goes manual, so
# nothing of it pulls unasked. The pass's guest writes "Lantern carry" into
# Session 1 and syncs it; the second guest, which never pulled that
# version, writes "Compass lunge" into its own Session 1 and drains: the
# push is held, the stored version merged first — its text filed as a
# conflict copy — and the push goes again (`drain --expect held`). Then
# both guests list the copy in Week 1, the copy holds the pass's guest's
# line and not the second guest's, and Session 1 the second guest's and
# not the other. The second guest stays manual for the flows after it.
# - Session 1 is found by the seed's "Mobility", which only it holds; the
#   notes are read back by the words typed into them (the suite header).
# - "waiting" on the second guest's status row is the gate before the
#   drain: the editor's save on Back has queued the edit.
# - A search page opens on its "Recent" list, whose rows carry the same
#   path as a hit, and keeps it for a moment after the query is typed: the
#   list is waited out (`--absent "Recent"`) before a hit is waited for,
#   or the path is ambiguous between two recent notes.
-d emulator-5558 expect id:sharing-sync-status "Up to date" --timeout 60
-d emulator-5558 tap id:sharing-sync-automatic
-d emulator-5558 expect "Syncs when you tap" "Only when you tap" --timeout 15
# The pass's guest: its line into Session 1, then "Sync now".
key back

key back
wait id:create-folder

wait id:search-field

expect --absent "Recent" --timeout 10
