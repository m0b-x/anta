# The Categories page end to end, on its content rows
# (docs/calendar-categories-roadmap.md §7 S2): the seeded Strength is
# archived through its ⋮ and lands under the Archived header, before the
# seeded Archive (its slot is kept), then restored through the same item and
# back above the header; it is dragged onto Other, the built-in above it, by
# a long press and put back, the order asserted both ways — the drag stays
# inside In use; deleted through its ⋮ with the confirm, which names its one
# seeded event, the message waited for and the row gone; then a category is
# created through the FAB, and the page scrolls to it by itself.
# - Reached as flow 18 reaches it. At 1.0 the nine built-ins, Strength, the
#   Archived header and Archive do not all fit one screen, and `expect` never
#   scrolls: the header's row is scrolled to before each ordered check.
# - The sections are read from the dump's order (`expect --ordered`) against
#   the headers' ids, never from their words.
# - The menu items are always listed and the archive item's id stays the
#   same whether it reads Archive or Restore; each tap holds 500 ms so the
#   write and the refresh land before the order is read.
# - The drag lifts the row by a long press anywhere on it (the delayed drag
#   listener lifts at 500 ms), so each drag holds 900 ms. Strength is
#   scrolled to first so it and Other are both on screen.
# - The delete's confirm is the shared dialog's id:sheet-confirm.
# - The new category is appended to In use; the create scrolls it into view
#   and flashes it, so the flow waits for its typed name without scrolling.
