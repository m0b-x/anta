# The alert sheet and its Custom sub-sheet (docs/calendar-language-tier-2-roadmap.md
# §3.2–§3.3), from a new event's Add alert: every row by id, Type to Alarm
# and back, the When menu with a preset, then Custom… (a unit, the stepper up
# and down, Done) read back on the When row, the Alarm sound row into the
# sound sheet and back, Done — and the editor's own row for the alert. The
# editor is left through its discard question, so nothing is written.
# - All day is switched off first: a timed event's When counts minutes and
#   its Custom sub-sheet has the unit chips. The event stays one-time, which
#   is what offers Remove after it rings.
# - A new alert has nothing to remove, and Time of day is an all-day event's
#   row: both are checked absent.
# - On the Alarm tier the line under the chips is the alarm hint or, on a
#   device that refuses full-screen alarms, the warning — so the tier is read
#   from the Reminder hint, present or absent.
# - The sound row is switched off on the Reminder tier (in place, dimmed), so
#   the sound sheet is opened from the Alarm tier.
# - A menu or a sub-sheet on top takes the sheet under it out of the tree:
#   waiting for id:alert-sheet-save is waiting for the menu, the Custom
#   sub-sheet or the sound sheet to be gone.
