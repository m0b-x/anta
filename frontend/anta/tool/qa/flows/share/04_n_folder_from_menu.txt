# A folder shared from its own menu, read on the other phone — no seam.
# The owner opens Training's ⋮ and taps "Share with …"; after a sync each
# the partner finds it under "From …" at its root and opens it: the
# read-only line under the bar, and the create buttons drawn disabled (a
# tap on either opens nothing). A note in it opens read-only: no edit
# mode, nothing to type into, its task list as it was. "Copy to my notes"
# puts a copy into a folder of the partner's own, and the copy takes an
# edit.
