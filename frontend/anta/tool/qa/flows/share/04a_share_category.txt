# The owner shares a custom category (docs/cloud-share-surfaces-roadmap.md
# §8.2 C1–C3, §8.4 R7). Strength holds the seeded "Lifting session" and an
# event the owner makes in the editor first; shared through the QA seam,
# both reach the partner's calendar, each read as the partner's, under the
# category's own name — and the partner's own editor never offers it. Then,
# with no second act, an event the owner adds to Strength arrives and the
# one it moves to Cardio (private) leaves.
# - The owner's events are made on today, all day (the editor's defaults),
#   so the day panel lists them whatever the date; the seeded event recurs
#   on Mondays and Thursdays, so it is read off the Upcoming card's day
#   list, never the day panel.
# - A made event has no stable id: its day-panel row is tapped by title
#   with `--nth 1`, because today's grid cell carries every title of the
#   day in its marker label and comes first in traversal order.
# - Runs between 04 and 05 (they sort so): the pair holds, nothing else is
#   shared, and both guests rest on Sync & sharing, one back from the root.
