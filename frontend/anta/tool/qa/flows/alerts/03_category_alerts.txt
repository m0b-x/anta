# A category's alerts (docs/category-alerts-and-digests-roadmap.md §6.1,
# §6.2, §6.4): the fixture's Birthday alert (qa-alert-category-birthday — a
# Reminder 30 min before a timed event, the day before at 09:00 for an
# all-day one) in the category editor's Alerts group and in the alert sheet
# it opens, which shows both When rows; then the one event it reaches, the
# yearly "Ana" (qa-alert-birthday, two days ahead), as an inherited row in
# the Alerts hub and in her editor. Nothing is written.
# - Starts on the calendar, where 02_remove_after leaves it; run on its own,
#   open the calendar first. It rings nothing: the inherited reminder is due
#   tomorrow at 09:00 whatever the hour the seed went in — Ana sits two days
#   out so that it is, and so the hub has it to list.
# - Birthday is the built-in `birthday`, its row id:category-row-birthday.
#   A built-in's name is a read row, so the editor is waited for on its
#   alert row, not the name field.
# - The Categories page has a search field of its own, so the settings page
#   is waited for by the row that opened the Categories page.
#   The row reads the all-day wording as its label and the timed one in its
#   caption, "Timed events: 30 min before · Reminder"; the all-day label
#   carries a clock time in the device's own format and is not read.
# - Opened from a category, the alert sheet shows a When row per shape —
#   id:alert-when for timed events, id:alert-when-all-day for all-day ones —
#   and the time of day; remove-after is an event's flag and is absent.
#   A sheet on top takes the editor under it out of the tree, so the words
#   read there are the sheet's own.
# - ✕ on the alert sheet hands nothing back, and the category editor is
#   unguarded: ✕ leaves it as it was.
# - Ana is reached through the hub rather than a day cell: two days ahead
#   can be outside the month the grid draws, and the hub's row opens her
#   detail sheet on her day wherever that is (AppNavigator.toCalendarOccurrence,
#   which takes the hub off the stack). The hub loads behind a spinner, and
#   the Digests group's Add row is there once it has; Ana's row is found by
#   its caption, "The day before, <time> · From Birthday", and its switch by
#   its spoken label.
# - In the editor the inherited row is a read row with its source in the
#   caption, "From Birthday · Reminder", and the Category alerts switch ends
#   the group; scrolling to the switch inside id:event-form brings the group
#   on screen (the header strip is the first scrollable). Nothing is changed,
#   so ✕ leaves without the discard question and the detail sheet is back.
