# The sort sheets through the ⋮ menu's Sort by and its chooser: the root's
# folders by name Z-A, then Week 1's notes by title A-Z and Z-A, each
# order read back with `expect --ordered`.
# - The root offers only the folders' sheet; a folder page offers both.
# - Training holds no note of its own (Week 1 does), so the notes are
#   sorted in Week 1. Each note's preview names the other, so a title
#   matches both rows: a row is told by a word only its own preview holds
#   — Squat is Session 1's, Deadlift Session 2's.
# - Week 1 opens on last updated: Session 2 (edited a minute later)
#   first. A-Z puts Session 1 first, Z-A Session 2 again.
# - The chooser's two ids (browser-sort-open-folders, -notes) are
#   temporary: they retire with the chooser in Slice 2 of the browser's
#   sheets rework.
