# A reorder by drag (docs/qa-pass-rework.md decision K): Training, the last
# of the three root folders (Inbox, Money, Training by name), dragged by its
# handle onto Inbox, the first, with no hold.
# - The row's long press opens its action sheet, whose Select is the way
#   into selection; only selection shows the drag handles.
# - A handle is keyed by its row's position in the list, the FOLDERS header
#   being 0: an import gives every folder a fresh id no step can spell.
# - The handle starts the drag on touch (ReorderableDragStartListener), so
#   the drag holds for 0 ms; a hold on the row would be its long press.
# - The drag goes by points (the fleet's 1280 × 2856 screen at text scale
#   1.0) because right after Select the list's semantics are stale: every
#   row's rect is reported where it was before the selection bar pushed the
#   body down by that bar's height (300 px here: the Scroll node still says
#   [0,0], and the first rebuild moves it to [0,300]), on the agent's dump
#   and on Android's own alike (seen 2026-10-23; the same on the 39b0c7d
#   build on 2026-10-24, so pre-existing; an app a11y bug left to the
#   owner). `drag id:browser-drag-handle-3 "Inbox"` would therefore press
#   300 px above Training's handle; the points below are the handle's
#   stale centre (1163,777) and Inbox's (640,484), each plus 300.
# - The order is asserted: `expect --ordered` reads the dump's traversal
#   order, which the stale rects do not touch — Inbox, Money, Training
#   before the drag, Training first after it, and still first once
#   selection is left. With the drag commented out the second assertion
#   fails as out of order (proved 2026-10-24).
wait "Training"
longpress "Training"
wait id:row-action-select
tap id:row-action-select
wait id:browser-drag-handle-3
wait id:row-action-select --gone
expect id:browser-drag-handle-1 id:browser-drag-handle-2
expect --ordered "Inbox" "Money" "Training"
drag 1163,1077 640,784 --hold 0
expect --ordered "Training" "Inbox" "Money"
look 02_reordered
key back
wait id:browser-drag-handle-3 --gone
expect --ordered "Training" "Inbox" "Money"
expect id:create-folder
errors
